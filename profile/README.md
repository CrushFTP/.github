## CrushFTP Highlights

- **File Server:** CrushFTP file server hosts folders on a computer you manage so named people can exchange files.
- **User Account:** CrushFTP user account is one person, with a password and a folder you assign.
- **SFTP Login:** CrushFTP sftp login is the protected sign-in for a transfer program.
- **Web Transfer:** CrushFTP web transfer lets someone upload or fetch a file in a browser.
- **Shared Folder:** CrushFTP shared folder is the directory those accounts are allowed to see.

## What Is CrushFTP

CrushFTP is a file server you run for a household, a class drop box, or a small office. CrushFTP file server is the service. CrushFTP user account keeps each person separate. You decide the password and CrushFTP shared folder, so the exchange stays limited to people you named. It is for files you are allowed to host, not for opening servers that are not yours.

CrushFTP sftp login suits a person who already uses a transfer client. CrushFTP web transfer suits someone who only has a browser, such as a relative sending photos or a student turning in a paper. Both paths can land in the same CrushFTP shared folder. A home machine or a small office computer can serve that role if you keep the account list short.

Start with two accounts and one folder. CrushFTP file server, CrushFTP user account, and CrushFTP shared folder are enough to see the shape. Test CrushFTP sftp login from one computer and CrushFTP web transfer from another. Widen the list only when those two paths behave.

## Starting with CrushFTP
